# Jarvis Phase 1 Functional Runtime

Implemented production-oriented architecture under `D:/Jarvis`:

- JSON config in `Config/settings.json`
- rotating logs in `Logs/jarvis.log`
- async event bus and dependency-friendly composition root
- plugin framework with Open App, Open Website, Google Search, and AI routing
- real PySide6 system tray icon and transparent animated floating orb
- OpenWakeWord microphone listener
- Faster-Whisper recognizer with CUDA preference and CPU fallback
- Piper text-to-speech invocation with WAV playback
- AI provider abstraction with Ollama default plus OpenAI, Gemini, and Claude REST providers
- dependency lock file generated by `pip freeze` at `requirements.lock`

## Validate

```bat
D:\Jarvis\Scripts\validate_phase1.bat
```

## Run the resident tray app

```bat
cd /d D:\Jarvis
venv\Scripts\python -m App.main
```

Jarvis stays resident until the tray menu `Quit` action is selected.
